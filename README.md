# KWADER - Smart HR & Attendance Management System

**KWADER** is a professional, cloud-based solution for managing human resources, attendance, and payroll. It integrates seamlessly with ZKTeco fingerprint devices through a dedicated synchronization agent.

## Project Structure

- **[kwader-app](./attendpay-app)**: The core web application (React-based) for HR management, dashboard, and reporting.
- **[sync-agent](./sync-agent)**: An Electron-based desktop application that connects local ZKTeco devices to the KWADER cloud.

## Key Features

- 🕒 **Real-time Attendance Tracking**: Live data from fingerprint devices.
- 👥 **Employee Management**: Comprehensive records and document management.
- 💰 **Automated Payroll**: Accurate salary calculations based on attendance rules.
- 🤖 **AI Assistant**: Smart HR assistant for data analysis and queries.
- 📡 **Device Sync**: Background synchronization with physical ZKTeco devices.
- 🧪 **Demo Mode**: Full system testing without the need for physical hardware.

## Quick Start

1. **Web App**: Navigate to `attendpay-app`, install dependencies, and run `npm start`.
2. **Sync Agent**: Navigate to `sync-agent`, install dependencies, and run `npm start`.
